# 🇷🇺 Русский

## 🚀 Представляем OverlayCross 2.0

**OverlayCross** — приложение для Windows, позволяющее создавать, настраивать и отображать собственный прицел поверх экрана.

**Версия 2.0 — крупное обновление проекта:** переработанный интерфейс, расширенная персонализация, сохранения прицелов и улучшенное управление.

### ✨ Что нового?

#### 🎨 Интерфейс
- Обновлённый чёрно-фиолетовый дизайн и удобная навигация по разделам.
- Масштабируемое окно с адаптивной компоновкой и поддержкой DPI.
- Интерактивный предпросмотр прицела.

#### 🎯 Прицел
- Два основных типа: **крест** и **точка**.
- Настройка цвета, размеров, толщины линий и размера точки.
- Независимая настройка горизонтальных и вертикальных линий.
- Регулировка промежутка между линиями креста.
- Мгновенное применение изменений.

#### 💾 Сохранения
- Именованные пресеты и несколько конфигураций прицела.
- Миниатюры сохранений, быстрое применение и удаление.
- Независимое хранение пресетов.

#### ⌨️ Горячие клавиши
- Глобальное включение и выключение прицела (**F6** по умолчанию).
- Переназначение сочетаний с Ctrl, Alt и Shift.
- Определение занятых комбинаций клавиш.

#### 🖥️ Мониторы и локализация
- Выбор монитора и переход на основной монитор, если выбранный недоступен.
- Русский и английский интерфейсы.
- Возможность добавлять переводы через JSON с резервными строками.

#### ⚙️ Дополнительные возможности
- Автозапуск с Windows и сворачивание при запуске.
- Сохранение настроек между сеансами и перенос старой конфигурации.
- Сброс настроек без удаления библиотеки прицелов.

### 📥 Установка
1. Откройте **Assets** под описанием релиза.
2. Скачайте установщик **OverlayCross 2.0** (`.exe`).
3. Запустите его и следуйте инструкциям.
4. Откройте OverlayCross и настройте прицел.

# 🇬🇧 English

## 🚀 Introducing OverlayCross 2.0

**OverlayCross** is a Windows application for creating, customizing, and displaying your own on-screen crosshair.

**Version 2.0 is a major update**, bringing a redesigned interface, expanded customization, crosshair presets, and improved controls.

### ✨ What's New?

#### 🎨 Interface
- Redesigned black-and-purple interface with convenient section navigation.
- Resizable window with an adaptive layout and DPI support.
- Interactive crosshair preview.

#### 🎯 Crosshair Customization
- Two main types: **Cross** and **Dot**.
- Adjustable colors, sizes, line thickness, and dot size.
- Independent horizontal and vertical line lengths.
- Customizable gap between crosshair lines.
- Instant application of changes.

#### 💾 Presets
- Named presets and multiple saved crosshair configurations.
- Preview thumbnails, quick loading, and deletion.
- Independently stored presets.

#### ⌨️ Hotkeys
- Global crosshair visibility toggle (**F6** by default).
- Custom shortcuts with Ctrl, Alt, and Shift modifiers.
- Detection of conflicting hotkey combinations.

#### 🖥️ Displays & Localization
- Monitor selection with fallback to the primary display.
- Russian and English interfaces.
- Additional JSON translations with fallback strings.

#### ⚙️ Additional Features
- Optional startup with Windows and start-minimized behavior.
- Persistent preferences and migration of older configuration data.
- Reset settings without deleting saved crosshair presets.

### 📥 Download & Installation
1. Open the **Assets** section below.
2. Download the **OverlayCross 2.0** installer (`.exe`).
3. Run the installer and follow the setup instructions.
4. Launch OverlayCross and customize your crosshair.

### 💻 System Requirements

| Component | Requirement |
|---|---|
| Operating system | Windows |
| Framework | .NET Framework 4.7.2 or later |
| Displays | One or more monitors |
| Internet | Not required for core functionality |

### ⚠️ Known Limitations
- Custom PNG crosshair editing is not yet implemented.
- Overlay functionality is not guaranteed in exclusive fullscreen games; windowed or borderless mode may be required.
